## 🌟 Présentation de la Plateforme Officielle

Ce dépôt héberge le site web officiel du **Sous-Comité AEEMCI de Koumassi** (Commune de Koumassi, Abidjan, Côte d'Ivoire).

Le projet comprend :
- 🏠 **Page d'Accueil** : compte à rebours dynamique, chiffres clés d'impact, mot du président et actualités.
- 📰 **Actualités & Événements** : Mahouloud, SECOFIS, SEFORES, Journée de l'Excellence, Iftar Solidaire.
- 🖼️ **Médiathèque & Galerie Photo** : albums photos interactifs.
- 👤 **Bureau Exécutif** : organigramme officiel des responsables.
- 📞 **Contact & Adhésion** : adhésions en ligne pour les militants.
- 🎬 **AEEMCI Studio** : espace d'administration privé pour le bureau exécutif.
